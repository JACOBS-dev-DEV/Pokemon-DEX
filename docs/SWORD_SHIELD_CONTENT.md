# Pokemon Sword / Shield Content Support

Pokemon-DEX treats supported game content separately from personal save data.

## Supported base games

- Pokemon Sword
- Pokemon Shield

## Supported Expansion Pass content

Both versions can describe and organize:

- The Isle of Armor
- The Crown Tundra

These entries are registry/documentation support only until the user explicitly starts tracking personal progress for that game or DLC.

## Storage rule

Adding a supported game or DLC to the registry does **not** create a personal profile, caught-Pokemon file, route file, wallet file, badge file, or journey log.

Personal files are created only when progress is intentionally tracked. This prevents Pokemon Shield or DLC support from being mistaken for an active save.

## Current tracked run

The currently active live-play data is Pokemon Sword. Shield and its DLC content are supported by the application but are not automatically treated as played, owned, completed, or progressed.

## Future DLC tracking

When DLC tracking is activated, it can reuse the same systems already used by the base game:

- My Dex / caught Pokemon
- area and route checklists
- trainer battles
- special encounters
- Pokemon Centers
- item pickups
- wallet/currencies
- story milestones
- team data

DLC-specific progress should remain separable from the base Galar journey while still belonging to the same Sword or Shield profile.
